# Nacht der Untoten — мультиплеер

## Структура
```
server.js            – штатная точка запуска
server-multiplayer.js – серверное состояние мира, попадания и экономика
package.json
public/index.html    – твоя игра (nacht_bunker.html) + 2 добавленных <script>
public/multiplayer.js – сетевой клиент и применение серверного состояния
```

## Запуск локально
```
npm install
npm start
```
Открой http://localhost:3000 в двух вкладках: ИГРАТЬ → МУЛЬТИПЛЕЕР → в одной «Создать лобби», в другой ввести код. Макс. 4 игрока. Когда хост нажимает «В ИГРУ», остальные участники автоматически переходят на свои стартовые позиции и получают общий мир; для управления нужно нажать «В ИГРУ» ещё раз — браузер не разрешает включать Pointer Lock без клика пользователя.

## Деплой: GitHub → Render
1. Залей папку в репозиторий GitHub (`node_modules` игнорируется через .gitignore).
2. render.com → New → **Web Service** → выбери репозиторий.
3. Build Command: `npm install` · Start Command: `npm start`
4. После деплоя открой выданный адрес `https://имя.onrender.com`.

Бесплатный план Render «засыпает» без запросов — первое подключение может занять ~30–60 сек.
Проверка работы: `/health`.

В мультиплеере сервер хранит общий счёт, покупки, двери, раунд и подтверждённое состояние зомби. Хост остаётся единственным источником спавна и ИИ: он передаёт позицию и скорость зомби, а сервер рассчитывает скорость их перемещения и рассылает компактный снимок. Визуальная модель, походка и анимации создаются локально, поэтому один зомби может выглядеть по-разному у каждого игрока. ИИ выбирает ближайшего активного игрока, сервер подтверждает урон как от оружия игроков, так и от атак зомби, и начисляет очки. В одиночном режиме игровая логика остаётся локальной.

## Клиент отдельно от сервера (GitHub Pages)
В `public/multiplayer.js` впиши `const SERVER_URL = 'https://имя.onrender.com';`
и подключи в HTML `<script src="https://имя.onrender.com/socket.io/socket.io.js"></script>`.

## Имя игрока
В консоли браузера: `MP.setName('Вася')`.
