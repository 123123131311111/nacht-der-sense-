# Nacht der Untoten — мультиплеер

## Структура
```
server.js            – штатная точка запуска
server-multiplayer.js – серверное состояние мира, попадания и экономика
package.json
public/index.html    – твоя игра (nacht_bunker.html) + 2 добавленных <script>
public/multiplayer.js – сетевой клиент и применение серверного состояния
```

## Запуск локально
```
npm install
npm start
```
Открой http://localhost:3000 в двух вкладках: ИГРАТЬ → МУЛЬТИПЛЕЕР → в одной «Создать лобби», в другой ввести код. Макс. 4 игрока. Когда хост нажимает «В ИГРУ», остальные участники автоматически переходят на свои стартовые позиции и получают общий мир; для управления нужно нажать «В ИГРУ» ещё раз — браузер не разрешает включать Pointer Lock без клика пользователя.

## Деплой: GitHub → Render
1. Залей папку в репозиторий GitHub (`node_modules` игнорируется через .gitignore).
2. render.com → New → **Web Service** → выбери репозиторий.
3. Build Command: `npm install` · Start Command: `npm start`
4. После деплоя открой выданный адрес `https://имя.onrender.com`.

Бесплатный план Render «засыпает» без запросов — первое подключение может занять ~30–60 сек.
Проверка работы: `/health`.

В мультиплеере сервер хранит общий счёт, покупки, двери, раунд и подтверждённое состояние зомби. Хост остаётся единственным источником спавна и ИИ: он передаёт позицию и скорость зомби, а сервер рассчитывает скорость их перемещения и рассылает компактный снимок. Визуальная модель, походка и анимации создаются локально, поэтому один зомби может выглядеть по-разному у каждого игрока. ИИ выбирает ближайшего активного игрока, сервер подтверждает урон как от оружия игроков, так и от атак зомби, и начисляет очки. В одиночном режиме игровая логика остаётся локальной.

## Клиент отдельно от сервера (GitHub Pages)
В `public/multiplayer.js` впиши `const SERVER_URL = 'https://имя.onrender.com';`
и подключи в HTML `<script src="https://имя.onrender.com/socket.io/socket.io.js"></script>`.

## Имя игрока
В консоли браузера: `MP.setName('Вася')`.

## Управление и интерфейс
- Выход в главное меню во время игры: на телефоне — кнопка «ВЫЙТИ» справа сверху (рядом с ⏸), на ПК — Esc → «✕ ВЫЙТИ В МЕНЮ». Нужно нажать дважды в течение 3 секунд. В мультиплеере выход закрывает соединение, и игрок убирается из комнаты.

## Круговая лестница
Центр (11, −9), радиус 3 м, один виток из 16 ступеней по 25 см, колонна в центре. Подъём — против часовой стрелки, вход и выход с севера. Ступени, колонна и перекрытие с круглым проёмом считаются аналитически (`spStepTop`, `stairHit` в `index.html`), поэтому по ним работают и игрок, и зомби. Параметры лежат в объекте `SP`.

## Звуки оружия
`public/sounds/shotgun-shot.mp3` — выстрел дробовика, `public/sounds/raygun-shot.mp3` — выстрел Ray Gun. Подключены через `SHOT_FILES`/`SHOT_GAIN`; если файл не загрузился, играет прежний синтезированный звук.

## Карта Verrückt
Запуск: карточка VERRUCKT в выборе карты (страница перезагрузится с `?map=verruckt`) или `http://localhost:3000/?map=verruckt`. Работает и в мультиплеере: карта хранится в комнате (таблица `MAPS` в `server-multiplayer.js`), гость с другой картой автоматически перезагружается на нужную.
Новая версия — закрытый двор с двумя противоположными проходами для зомби, центральным фонтаном, машиной, Mystery Box напротив фонтана и двумя двухэтажными корпусами. В каждом корпусе есть лестница; Speed Cola находится в левом, Double Tap — в правом.

## Перк «Строитель» (Verrückt)
4000 очков, автомат у фасада правого дома (напротив Быстрого возрождения). Скидка 75% на починку окон (250 → 63) и баррикад (постройка 1500 → 375, починка 2000 → 500); окно чинится целиком мгновенно, без удержания E и без ожидания 30 с; сломанные окна и баррикады подсвечиваются красной обводкой сквозь стены. Константы: `BLD_*` в `index.html` и `BUILDER_*` / `MAPS.verruckt.builder` в `server-multiplayer.js` (должны совпадать).

## Меню и помощь
«Помощь» — вкладки: Управление, Nacht, Verrückt, Перки (разбор карт: двери, окна, оружие, перки, советы). В настройках — яркость и контраст (сохраняются).

## Осколочные гранаты
Клавиша **G** (на телефоне — кнопка ГРАНАТА): 2 штуки выдаётся в начале каждого раунда, взрыв через 2,3 с, радиус 6,5 м, урон до 800. Нож перезаряжается 0,5 с.
